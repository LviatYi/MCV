# Custom Tool Capability Prompt

This prompt layer is a placeholder for describing a project-specific or organization-specific tool.

## Required Fields

- Tool name
- Purpose
- Supported inputs
- Expected outputs
- Safe usage rules
- Failure handling
- Escalation conditions

## Guidance

- Keep the tool contract concrete.
- Describe what the tool is allowed to change.
- Describe what the tool must never be used for.
- State whether human confirmation is required before high-impact actions.
